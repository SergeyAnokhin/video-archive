# Frozen V1 Specification (archive)

This folder holds the complete pre-implementation specification for V1 of the Video Archive application. V1 is fully implemented (all roadmap stages are done), so these documents are **archived and frozen**: they are kept for historical reference, are not updated with code changes, and must not be treated as a description of current behavior.

**Do not read these documents by default.** Consult them only when explicitly asked, or when a question is specifically about the original V1 spec intent (e.g. "what did the spec say about X?"). For current behavior, trust the code and the living docs in [`docs/`](../README.md).
