## Notes and conventions

- **Copy-to-clipboard buttons**: no shared utility — every instance inlines the same small pattern: `await navigator.clipboard.writeText(text)`, a `copied` boolean reset via `setTimeout(~1500ms)`, and a `Check`/`Copy` icon swap. Reuse the shape rather than introducing a hook.
- **Adding/removing a theme preset** touches all of these together: (1) `THEME_PRESETS` in `frontend/src/types/api.ts`, (2) a `[data-theme="X"]` block in `styles/theme.css`, (3) a `THEME_ICON` entry in `themeIcons.ts`, (4) `theme.<key>` labels in `en.json` + `ru.json`, (5) `THEME_PRESETS` in `backend/app/interface_settings.py`, (6) the `Literal` in `backend/app/routers/interface_settings.py` (synced by hand — no shared constant across the language boundary).
- **API calls**: always through [`frontend/src/api/client.ts`](../frontend/src/api/client.ts) (`api`/`tryApi`/`rawApi`), never inline `fetch('/api/...')`; shared server state lives in the contexts above. Pick `api()` when the caller surfaces the error (try/catch → error state), `tryApi()` when failure should be silent (polling, suggestion fetches, fire-and-forget saves).
- **Compact status/labels**: prefer an icon or emoji over a text label when space is tight (job cards, status indicators) — shape + color reads at a glance and doesn't wrap. Keep the full word reachable via `title` (hover tooltip) and `aria-label` (accessibility) on the icon element, rather than dropping the information entirely. See `JobsModal.tsx`'s `STATUS_ICON` map and its running-job meta row (`Timer`/`Hourglass` icons with `formatElapsedCompact` text, full sentence in `title`) for the pattern.
