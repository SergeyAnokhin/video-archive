## Notes and conventions

- **Copy-to-clipboard buttons**: no shared utility — every instance inlines the same small pattern: `await navigator.clipboard.writeText(text)`, a `copied` boolean reset via `setTimeout(~1500ms)`, and a `Check`/`Copy` icon swap. Reuse the shape rather than introducing a hook.
- **Adding/removing a theme preset** touches all of these together: (1) `THEME_PRESETS` in `frontend/src/types/api.ts`, (2) a `[data-theme="X"]` block in `styles/theme.css`, (3) a `THEME_ICON` entry in `themeIcons.ts`, (4) `theme.<key>` labels in `en.json` + `ru.json`, (5) `THEME_PRESETS` in `backend/app/interface_settings.py`, (6) the `Literal` in `backend/app/routers/interface_settings.py` (synced by hand — no shared constant across the language boundary).
- **No API-client module**: components call `fetch('/api/...')` directly; shared server state lives in the contexts above.
