# Code Map — Backend Tests

Part of the [code map](code-map.md). **Update this file whenever test files are added, moved, or removed.** Shared test conventions (isolated DB/secrets, `make_video()`, the SMB fake, mocked providers) are summarized in [development.md](development.md#tests). Keep entries short — what each suite covers and its gotchas.

## `backend/tests/` — pytest

| Path | Role |
| --- | --- |
| [`backend/pytest.ini`](../backend/pytest.ini) | `pythonpath = .` so `tests/` can `import app.*`. Run with `python -m pytest` from `backend/`. |
| [`backend/tests/conftest.py`](../backend/tests/conftest.py) | Shared fixtures: autouse `isolated_secrets_file` (patches `secrets_store.SECRETS_PATH`), `engine` (temp SQLite per test), `source` (active `local` source over a temp dir; GIFs land on the source itself via `app/media.py` path helpers), `make_files()` (dummy files), `make_video()` (tiny real ffmpeg clip, fixed 5fps), `FakeSMBFS` + `fake_smb`/`smb_source` (in-memory `smbclient` fake). **GIF gotcha:** sampling faster than 5fps yields duplicate frames Pillow may collapse — assert lower bounds, never exact `n_frames`. |
| [`backend/tests/test_jobs.py`](../backend/tests/test_jobs.py) | Job state machine: cancel/restart/delete gating, retention sweep, pause/resume, the CPU/network lane partition (incl. a `threading.Barrier` concurrency proof), live `failed_item_count`, force-cancel freeing a lane from an unresponsive handler, `claim_next_queued_job()`'s atomic claim under two racing threads (only one may claim a given job). |
| [`backend/tests/test_jobs_router.py`](../backend/tests/test_jobs_router.py) | HTTP job lifecycle: `rescan-directory` → cancel/restart/delete; pause/resume 404/409 validation. **Deliberately does not test `GET /api/logs/stream`** — `TestClient`'s sync bridge hangs on endless SSE; drive `stream_logs()` directly with asyncio if ever needed. |
| [`backend/tests/test_request_logging.py`](../backend/tests/test_request_logging.py) | `RequestLoggingMiddleware`: quiet polling routes stay silent on success but log on failure; normal routes always log. |
| [`backend/tests/test_system_stats.py`](../backend/tests/test_system_stats.py) | `GET /api/system/stats` shape, and process-tree CPU/memory summing with a faked child process (a process's first `cpu_percent()` call always reads 0.0 — CPU counts from the second poll on). |
| [`backend/tests/test_backend_health_settings.py`](../backend/tests/test_backend_health_settings.py) | Backend-health settings singleton: defaults/round-trip, independent clamping of both timeouts, HTTP round trip. |
| [`backend/tests/test_conversion.py`](../backend/tests/test_conversion.py) | Conversion against real ffmpeg/ffprobe (auto-skipped if absent): profile CRUD (incl. `preset` round-trip), production replace, test-mode preserve, invalid-output safety, variant sweeps, directory recursion/skip-processed, parallel batches, per-stage progress, tuning tags, the min-size-reduction gate, `probe_media()` null-stdout and non-ASCII path regressions. **Gotcha:** an autouse fixture pins `min_size_reduction_percent` to 0 — a tiny default clip barely compresses; gate tests set their own threshold, replace-mechanics tests use `size="480x360", duration=1.0` clips that genuinely shrink. |
| [`backend/tests/test_conversion_router.py`](../backend/tests/test_conversion_router.py) | HTTP validation only: profile CRUD, trigger 404s, variants-require-test-mode 400. |
| [`backend/tests/test_conversion_script.py`](../backend/tests/test_conversion_script.py) | "Generate conversion script" feature: `enumerate_directory_files()`'s test-artifact exclusion/directory scoping, `generate_powershell_script()`'s software-vs-hardware-encoder `-preset` inclusion and rendered file list, and the `POST /jobs/generate-conversion-script` endpoint (profile 404, override round-trip). |
| [`backend/tests/test_preview.py`](../backend/tests/test_preview.py) | Preview generation against real ffmpeg (auto-skipped if absent): sampling edge cases, layout validation, preset protection, collage + GIF rendering (clip mode, crossfade), the preview job (file/directory scope, folder GIFs, skip-processed, parallelism), progress events, and blur-only degradation with detection models absent. |
| [`backend/tests/test_preview_router.py`](../backend/tests/test_preview_router.py) | HTTP: layout CRUD (built-in 409), live geometry endpoint, preview-settings GET/PUT, trigger 404s, collage/GIF image serving. |
| [`backend/tests/test_similarity.py`](../backend/tests/test_similarity.py) | aHash signatures: video signatures against real ffmpeg (unprobeable → `None`, near-duplicate ranking, preview-job side effect, `/similar`); image signatures without ffmpeg (roundtrip, same-kind scoping, tag-job side effect, lazy `/similar` fallback). |
| [`backend/tests/test_tagging.py`](../backend/tests/test_tagging.py) | Tag vocabulary CRUD, settings round trips, prompt/score parsing, frame/collage prep against real ffmpeg, the `tag` job (file/directory scope, skip-processed, top-N, re-tag replaces) with the provider chain stubbed, the standalone-image branch, the three-tag-pool logic, and the migration 26 backfill. |
| [`backend/tests/test_tag_lab.py`](../backend/tests/test_tag_lab.py) | Tag Lab: `run_tag_lab()` success shape (video + image) and error paths with `score_tags_with_entry` stubbed — incl. `ProviderError`'s raw response surviving into `TagLabError`; `apply_tag_lab_result()` (mixed scored/manual tags, deleted-tag drop, apply-KPI recording). |
| [`backend/tests/test_tag_lab_feedback.py`](../backend/tests/test_tag_lab_feedback.py) | The two rating signals: tag votes → like-ratio math, `record_apply()`'s unchanged-vs-changed comparison, `not_applied_count`, aggregation across runs and models. |
| [`backend/tests/test_provider_entries.py`](../backend/tests/test_provider_entries.py) | Service-level provider entry CRUD: sort order, name auto-generation, key storage/masking/rotation, delete, reorder validation. |
| [`backend/tests/test_tagging_router.py`](../backend/tests/test_tagging_router.py) | HTTP: tag CRUD/autocomplete (incl. color round-trip), tag filters on `/api/files`, manual assign/remove (ad-hoc never joins the AI pool), `category` param, the user-defined-tag endpoint, tagging-settings, provider-entries endpoints (key only ever in export), tag-job trigger validation. |
| [`backend/tests/test_tags.py`](../backend/tests/test_tags.py) | `top_tags_for_directory_subtree()`: recursive frequency ranking, tie-break, 5-item cap. |
| [`backend/tests/test_providers.py`](../backend/tests/test_providers.py) | Per-client request construction and response parsing with `httpx` monkeypatched: URL/headers/payload per provider, score + `UsageInfo` parsing, `ProviderError` on HTTP/malformed responses (incl. raw response attachment), `list_models()` filtering. |

| [`backend/tests/test_sources_smb.py`](../backend/tests/test_sources_smb.py) | SMB against the fake: UNC building, scandir/exists, retry-on-connection-error, `local_copy()`/`commit_new_file()`, `test_connection()`, scan/directory ops, and (real-ffmpeg-gated) convert/preview/tag handlers over SMB.
