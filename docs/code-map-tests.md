# Code Map — Backend Tests

Part of the [code map](code-map.md). **Update this file whenever test files are added, moved, or removed.** Shared test conventions (isolated DB/secrets, `make_video()`, the SMB fake, mocked providers) are summarized in [development.md](development.md#tests). Keep entries short — what each suite covers and its gotchas.

## `backend/tests/` — pytest

| Path | Role |
| --- | --- |
| [`backend/pytest.ini`](../backend/pytest.ini) | `pythonpath = .` so `tests/` can `import app.*`. Run with `python -m pytest` from `backend/`. |
| [`backend/tests/conftest.py`](../backend/tests/conftest.py) | Shared fixtures. Autouse isolation: `isolated_secrets_file` (patches `secrets_store.SECRETS_PATH`) so tests never touch real secrets. `engine` — temp SQLite DB per test (seeded via `init_db()`; `provider_entries` starts empty). `source` — active `local` source over a temp dir; GIF previews land under `source["root"] / preview_gif_relative_path(...)` / `folder_gif_relative_path(...)` (`app/media.py`) since they're written onto the source itself, not a backend-local cache. `make_files()` — dummy non-decodable files; `make_video()` — a tiny *real* ffmpeg-encoded video (`testsrc`, fixed 5fps) for suites needing real ffprobe/ffmpeg. **GIF gotcha:** sampling faster than that 5fps yields duplicate frames Pillow may collapse — assert lower bounds/durations, never exact `n_frames`. `FakeSMBFS` + `fake_smb`/`smb_source` — in-memory fake of the `smbclient` API surface, so `SMBBackend` code runs without a real server. |
| [`backend/tests/test_jobs.py`](../backend/tests/test_jobs.py) | Job state machine: cancel (queued/running/paused), restart/delete gating, retention sweep, pause/resume round trips, the CPU/network lane partition (incl. a `threading.Barrier` proof both lanes truly run concurrently), live `failed_item_count`, and force-cancel freeing a lane from an unresponsive (blocking, checkpoint-less) handler. |
| [`backend/tests/test_jobs_router.py`](../backend/tests/test_jobs_router.py) | HTTP lifecycle for `rescan-directory` → cancel/restart/delete; pause/resume endpoint 404/409 validation. **Deliberately does not test `GET /api/logs/stream`** — `TestClient`'s sync bridge hangs on endless SSE; drive `stream_logs()` directly with asyncio if ever needed. |
| [`backend/tests/test_request_logging.py`](../backend/tests/test_request_logging.py) | `RequestLoggingMiddleware`: quiet polling routes stay silent on success but still log on failure; a normal route always logs with its path template and route-name-derived purpose. |
| [`backend/tests/test_conversion.py`](../backend/tests/test_conversion.py) | Conversion against real ffmpeg/ffprobe (auto-skipped if absent): profile CRUD, production replace, test-mode preserve, invalid-output safety, variant sweeps, directory recursion/skip-processed, parallel batches, per-stage progress events, tuning-parameter tags, and the min-size-reduction gate (skip below threshold / replace above / variants exempt). **Gotcha:** an autouse fixture pins `min_size_reduction_percent` to 0 — a tiny default `make_video()` clip barely compresses (can even grow); gate tests set their own threshold, replace-mechanics tests use `size="480x360", duration=1.0` clips that genuinely shrink. Regression: `probe_media()` null-stdout and non-ASCII (Cyrillic) path handling. |
| [`backend/tests/test_conversion_router.py`](../backend/tests/test_conversion_router.py) | HTTP validation only: profile CRUD, trigger 404s, variants-require-test-mode 400. |
| [`backend/tests/test_conversion_settings.py`](../backend/tests/test_conversion_settings.py) | Conversion settings singleton: defaults/round-trip, out-of-range clamping, HTTP endpoint. |
| [`backend/tests/test_preview.py`](../backend/tests/test_preview.py) | Preview generation against real ffmpeg (auto-skipped if absent): sampling edge cases, layout tile validation, preset protection/CRUD, collage + GIF rendering (aspect ratio, clip mode, `segment_sizes`, crossfade), the preview job (file scope → collage next to the video, GIF in the local cache; directory recursion, folder GIFs at every level, skip-processed, artifact exclusion, multi-batch parallelism), item-key/per-stage progress events, and blur-only degradation with detection models absent. |
| [`backend/tests/test_preview_router.py`](../backend/tests/test_preview_router.py) | HTTP: layout CRUD (built-in 409, invalid 400), live geometry endpoint, preview-settings GET/PUT, trigger 404s, image serving (both the collage and GIF fixtures written straight next to/onto the source, via `sibling_relative_path()`/`preview_gif_relative_path()`/`folder_gif_relative_path()`). |
| [`backend/tests/test_similarity.py`](../backend/tests/test_similarity.py) | aHash signatures against real ffmpeg: unprobeable → `None`, near-duplicate vs. distinct ranking, the preview job storing a signature as a side effect, and the `/similar` endpoint. Plus (no ffmpeg needed) `compute_image_signature()` roundtrip, `find_similar()` same-kind scoping (video never matches image), the tag job storing an image's signature as a side effect, and `/similar`'s lazy on-demand fallback for an untagged image. |
| [`backend/tests/test_tagging.py`](../backend/tests/test_tagging.py) | Tag vocabulary CRUD, settings round trips, prompt building/score parsing, frame/collage prep against real ffmpeg, and the `tag` job (file/directory scope, skip-processed, top-N, re-tag replaces) with the provider chain stubbed — no real network calls. Plus the standalone-image branch (image prep, image/mixed-directory tag jobs), the three-tag-pool logic (`list_tags`, `get_or_create_tag` promotion, `assign_user_defined_tag`, `list_used_tags`), and the migration 26 backfill. |
| [`backend/tests/test_tag_lab.py`](../backend/tests/test_tag_lab.py) | Tag Lab (single-entry, no-fallback, synchronous alternative to the `tag` job): `run_tag_lab()` success shape (`run_id` + images/prompt/raw response/usage/ranked tags, works for video and standalone images) and its error paths (missing file/entry/vocabulary, no API key, provider error, source file gone) with `registry.score_tags_with_entry` stubbed — including that a `ProviderError`'s `raw_text`/`raw_full_response` survive into the resulting `TagLabError`; `apply_tag_lab_result()` mixing model-scored and manually-typed tags, silently dropping a since-deleted `tag_id`, and (with `run_id`) recording the apply-KPI end to end. |
| [`backend/tests/test_tag_lab_feedback.py`](../backend/tests/test_tag_lab_feedback.py) | `tag_lab_feedback.py`'s two rating signals: `record_run`/`set_tag_vote` (like/dislike/change/clear) → `get_model_stats()` like-ratio math; `record_apply()`'s unchanged-vs-changed tag-id-set comparison (exact match, added, removed); `not_applied_count` derivation for a run with no apply row; aggregation across multiple runs of the same model and across distinct models (`get_all_model_stats()`). |
| [`backend/tests/test_provider_entries.py`](../backend/tests/test_provider_entries.py) | Service-level provider entry CRUD: sort-order increments, name auto-generation, key storage/masking, multiple entries per type, key rotation, delete (row + secret), reorder validation. |
| [`backend/tests/test_tagging_router.py`](../backend/tests/test_tagging_router.py) | HTTP: tag CRUD/autocomplete (incl. `color` round-trip and the deterministic fallback for a tag with none set), tag filters on `/api/files`, manual per-file tag assign/remove (an ad-hoc typed tag never joins the AI vocabulary), the `category` query param on `GET /api/tags`, the user-defined-tag endpoint (`POST /files/{id}/tags/user-defined`, both pick-existing and create-new paths, 404/422 validation), tagging-settings, provider-entries endpoints (key never in non-export responses; export includes it), tag-job trigger validation. |
| [`backend/tests/test_tags.py`](../backend/tests/test_tags.py) | `top_tags_for_directory_subtree()`: frequency ranking recursively across a folder's subtree (all three tag pools count, a `score = 0` tag doesn't), alphabetical tie-break, and the 5-item cap. |
| [`backend/tests/test_providers.py`](../backend/tests/test_providers.py) | Per-client request construction and response parsing with `httpx` monkeypatched: URL/headers/payload shape per provider, score + `UsageInfo` parsing, `ProviderError` on HTTP/malformed responses (incl. `raw_text`/`raw_full_response` being attached whenever the provider actually returned something before parsing failed), `list_models()` filtering (openrouter/gemini/mistral; FAL has none). |
| [`backend/tests/test_tagging_batch.py`](../backend/tests/test_tagging_batch.py) | Batch tagging: `create_batch()`/`poll_batch()` request/response handling for gemini/mistral (mocked `httpx`), and directory-scope orchestration — all-succeed, partial fallback, submission/poll failure falling back for all, dead-entry marking, the real (unstubbed) two-entry fallback chain, submission persisted before polling, restart-resume without re-submitting, and forgotten submissions falling back per-file. |
| [`backend/tests/test_provider_usage.py`](../backend/tests/test_provider_usage.py) | `estimate_cost_usd()` known/unknown/missing-token cases against seeded `model_pricing` rows; `log_usage()` + `get_usage_summary()` aggregation; the registry's logging hook on success and failure (mocked client). |
| [`backend/tests/test_model_pricing.py`](../backend/tests/test_model_pricing.py) | `model_pricing.py`: seeded-price lookup, manual `upsert_price()` (overwrite + new pair), and `refresh_openrouter_prices()` scoped to configured OpenRouter entries (`openrouter.fetch_pricing` monkeypatched) including the updated/not-found split; plus `openrouter.py::fetch_pricing()`'s own response-parsing test (`httpx` monkeypatched, no real network call). |
| [`backend/tests/test_batch_submissions.py`](../backend/tests/test_batch_submissions.py) | `batch_submissions` CRUD, `list_active()`/`forget()` semantics, idempotent `requeue_stalled_jobs()`, and the `GET/DELETE /api/jobs/batch-submissions` endpoints (fresh-`TestClient` pattern). |
| [`backend/tests/test_sources_smb.py`](../backend/tests/test_sources_smb.py) | SMB against the fake: UNC path building, scandir/exists, retry-on-connection-error, `local_copy()`/`commit_new_file()`, `test_connection()`, mkdir/rmdir, scan discovery, directory ops, and (real-ffmpeg-gated) the convert/preview/tag handlers over SMB — asserting both the collage and the GIF get uploaded onto the share. |
| [`backend/tests/test_source_router.py`](../backend/tests/test_source_router.py) | HTTP `/api/source*`: local + SMB connect/test-connection/reconnect flows, validation errors, switch-backs-up-and-auto-restores round trip, active-source resubmit no-op, and per-source SMB credential independence. |
| [`backend/tests/test_playback.py`](../backend/tests/test_playback.py) | Playback endpoints for both protocols: mode/URL/direct-path payload, Range handling (unit + status/header cases), settings round trip. | [`backend/tests/test_backup.py`](../backend/tests/test_backup.py) | Backup/restore/maintenance at service level: zip contents, retention, delete, restore under a new source id, newer-schema/missing-package rejection, secrets and `provider_entries` round trips, `include_global=False` skipping global tables, SMB parity, `cleanup` stale-record handling. |
| [`backend/tests/test_sources_router.py`](../backend/tests/test_sources_router.py) | HTTP `/api/sources*`: list with preview-GIF stats (live for the active source only, zero for inactive even when they have GIFs of their own), activate (switch/no-op/404), forget (active-source 400, and confirms an inactive source's own files are never touched), clearing the active source's preview GIFs (incl. the has-preview DB-flag reset) and 400-rejecting the same for an inactive source. |
