# Code Map — Backend Tests

Part of the [code map](code-map.md). **Update this file whenever test files are added, moved, or removed.** Shared test conventions (isolated DB/secrets/preview-cache, `make_video()`, the SMB fake, mocked providers) are summarized in [development.md](development.md#tests). Keep entries short — what each suite covers and its gotchas.

## `backend/tests/` — pytest

| Path | Role |
| --- | --- |
| [`backend/pytest.ini`](../backend/pytest.ini) | `pythonpath = .` so `tests/` can `import app.*`. Run with `python -m pytest` from `backend/`. |
| [`backend/tests/conftest.py`](../backend/tests/conftest.py) | Shared fixtures. Autouse isolation: `isolated_secrets_file` (patches `secrets_store.SECRETS_PATH`) and `isolated_preview_cache` (patches `preview_cache.PREVIEW_CACHE_DIR`) so tests never touch real secrets/cache. `engine` — temp SQLite DB per test (seeded via `init_db()`; `provider_entries` starts empty). `source` — active `local` source over a temp dir. `make_files()` — dummy non-decodable files; `make_video()` — a tiny *real* ffmpeg-encoded video (`testsrc`, fixed 5fps) for suites needing real ffprobe/ffmpeg. **GIF gotcha:** sampling faster than that 5fps yields duplicate frames Pillow may collapse — assert lower bounds/durations, never exact `n_frames`. `FakeSMBFS` + `fake_smb`/`smb_source` — in-memory fake of the `smbclient` API surface, so `SMBBackend` code runs without a real server. |
| [`backend/tests/test_jobs.py`](../backend/tests/test_jobs.py) | Job state machine: cancel (queued/running/paused), restart/delete gating, retention sweep, pause/resume round trips, the CPU/network lane partition (incl. a `threading.Barrier` proof both lanes truly run concurrently), live `failed_item_count`, and force-cancel freeing a lane from an unresponsive (blocking, checkpoint-less) handler. |
| [`backend/tests/test_jobs_router.py`](../backend/tests/test_jobs_router.py) | HTTP lifecycle for `rescan-directory` → cancel/restart/delete; pause/resume endpoint 404/409 validation. **Deliberately does not test `GET /api/logs/stream`** — `TestClient`'s sync bridge hangs on endless SSE; drive `stream_logs()` directly with asyncio if ever needed. |
| [`backend/tests/test_conversion.py`](../backend/tests/test_conversion.py) | Conversion against real ffmpeg/ffprobe (auto-skipped if absent): profile CRUD, production replace, test-mode preserve, invalid output never touching the source, variant sweeps, directory recursion/skip-processed/artifact exclusion, multi-batch parallel runs, per-stage progress events, tuning-parameter tags. Regression tests: `probe_media()` returns `None` (not raises) on null stdout, and handles non-ASCII (Cyrillic) paths via explicit UTF-8 subprocess decoding. |
| [`backend/tests/test_conversion_router.py`](../backend/tests/test_conversion_router.py) | HTTP validation only: profile CRUD, trigger 404s, variants-require-test-mode 400. |
| [`backend/tests/test_preview.py`](../backend/tests/test_preview.py) | Preview generation against real ffmpeg (auto-skipped if absent): sampling edge cases, layout tile validation, preset protection/CRUD, collage + GIF rendering (aspect ratio, clip mode, `segment_sizes`, crossfade), the preview job (file scope → local cache; directory recursion, folder GIFs at every level, skip-processed, artifact exclusion, multi-batch parallelism), item-key/per-stage progress events, and blur-only degradation with detection models absent. |
| [`backend/tests/test_preview_router.py`](../backend/tests/test_preview_router.py) | HTTP: layout CRUD (built-in 409, invalid 400), live geometry endpoint, preview-settings GET/PUT, trigger 404s, image serving (fixtures written straight into the local preview cache). |
| [`backend/tests/test_similarity.py`](../backend/tests/test_similarity.py) | aHash signatures against real ffmpeg: unprobeable → `None`, near-duplicate vs. distinct ranking, the preview job storing a signature as a side effect, and the `/similar` endpoint. |
| [`backend/tests/test_tagging.py`](../backend/tests/test_tagging.py) | Tag vocabulary CRUD, tagging/secrets settings round trips, prompt building/score parsing (`providers/base.py`), frame/collage prep against real ffmpeg, and the `tag` job (file/directory scope, skip-processed, artifact exclusion, top-N, re-tag replaces) with `score_tags_with_fallback` stubbed — no real network calls. |
| [`backend/tests/test_provider_entries.py`](../backend/tests/test_provider_entries.py) | Service-level provider entry CRUD: sort-order increments, name auto-generation, key storage/masking, multiple entries per type, key rotation, delete (row + secret), reorder validation. |
| [`backend/tests/test_tagging_router.py`](../backend/tests/test_tagging_router.py) | HTTP: tag CRUD/autocomplete, tag filters on `/api/files`, manual per-file tag assign/remove, tagging-settings, provider-entries endpoints (key never in non-export responses; export includes it), tag-job trigger validation. |
| [`backend/tests/test_providers.py`](../backend/tests/test_providers.py) | Per-client request construction and response parsing with `httpx` monkeypatched: URL/headers/payload shape per provider, score + `UsageInfo` parsing, `ProviderError` on HTTP/malformed responses, `list_models()` filtering (openrouter/gemini/mistral; FAL has none). |
| [`backend/tests/test_tagging_batch.py`](../backend/tests/test_tagging_batch.py) | Batch tagging: `create_batch()`/`poll_batch()` request/response handling for gemini/mistral (mocked `httpx`), and directory-scope orchestration — all-succeed, partial fallback, submission/poll failure falling back for all, dead-entry marking, the real (unstubbed) two-entry fallback chain, submission persisted before polling, restart-resume without re-submitting, and forgotten submissions falling back per-file. |
| [`backend/tests/test_provider_usage.py`](../backend/tests/test_provider_usage.py) | `estimate_cost_usd()` known/unknown/missing-token cases; `log_usage()` + `get_usage_summary()` aggregation; the registry's logging hook on success and failure (mocked client). |
| [`backend/tests/test_batch_submissions.py`](../backend/tests/test_batch_submissions.py) | `batch_submissions` CRUD, `list_active()`/`forget()` semantics, idempotent `requeue_stalled_jobs()`, and the `GET/DELETE /api/jobs/batch-submissions` endpoints (fresh-`TestClient` pattern). |
| [`backend/tests/test_sources_smb.py`](../backend/tests/test_sources_smb.py) | SMB against the fake: UNC path building, scandir/exists, retry-on-connection-error, `local_copy()`/`commit_new_file()`, `test_connection()`, mkdir/rmdir, scan discovery, directory ops, and (real-ffmpeg-gated) the convert/preview/tag handlers over SMB — asserting previews land in the local cache, not on the share. |
| [`backend/tests/test_source_router.py`](../backend/tests/test_source_router.py) | HTTP `/api/source*`: local + SMB connect/test-connection/reconnect flows, validation errors, switch-backs-up-and-auto-restores round trip, active-source resubmit no-op, and per-source SMB credential independence. |
| [`backend/tests/test_playback.py`](../backend/tests/test_playback.py) | Playback endpoints for both protocols: mode/URL/direct-path payload, Range handling (unit + status/header cases), settings round trip. Byte-level checks go against `access.open_range()` directly (no async test runner in this project). |
| [`backend/tests/test_backup.py`](../backend/tests/test_backup.py) | Backup/restore/maintenance at service level: zip contents, retention, delete, restore under a new source id, newer-schema/missing-package rejection, secrets and `provider_entries` round trips, `include_global=False` skipping global tables, SMB parity, `cleanup` stale-record handling. |
| [`backend/tests/test_sources_router.py`](../backend/tests/test_sources_router.py) | HTTP `/api/sources*`: list with cache stats, activate (switch/no-op/404), forget (active-source 400), per-source preview-cache clearing incl. the active-source flag reset. |
| [`backend/tests/test_backup_router.py`](../backend/tests/test_backup_router.py) | HTTP `/api/backups*` + `/api/backup-settings` + maintenance triggers: full create → list → wipe → restore → delete lifecycle through the real `JobWorker`. |
| [`backend/tests/test_interface_settings.py`](../backend/tests/test_interface_settings.py) | Interface settings singleton: defaults/round-trip at service and HTTP level. |
| [`backend/tests/test_performance_settings.py`](../backend/tests/test_performance_settings.py) | Performance settings singleton: defaults/round-trip, out-of-range clamping, HTTP endpoint. |
| [`backend/tests/test_network_info.py`](../backend/tests/test_network_info.py) | `get_lan_addresses()` shape checks and the `GET /api/app/network-info` payload. |
| [`backend/tests/test_status.py`](../backend/tests/test_status.py) | `compute_directory_status()`: subtree scoping (incl. the `a`-vs-`ab` prefix case), artifact/unsupported exclusion, size summing, `top_variant_tags` ranking; `GET /api/tree` with `include_status`/`depth`/404. |
| [`backend/tests/test_directories_router.py`](../backend/tests/test_directories_router.py) | `GET /api/directories/children` returns only video-supported files; `variant_tags` on sweep siblings. |
| [`backend/tests/test_directory_ops.py`](../backend/tests/test_directory_ops.py) | HTTP folder create/delete/favorite: creation (row + physical folder), `invalid_name`/collision/missing-parent errors, empty-only delete vs. `directory_not_empty`, favorite round trip. |
| [`backend/tests/test_files_router.py`](../backend/tests/test_files_router.py) | File delete/move over HTTP (incl. sibling preview assets and error codes), `is_variant`/`is_original` markers, `media-info` (404 / graceful nulls / joined conversion profile), and variant preview fallback onto the original sibling's cached assets. |
| [`backend/tests/test_pure_helpers.py`](../backend/tests/test_pure_helpers.py) | Pure helpers, no ffmpeg/models/DB: `media` naming rules (artifacts, sibling/GIF paths, variant stem/suffix/tags), `conversion` command building (`build_ffmpeg_command()` argv, max-dimension, variant suffix), `effective_aspect_ratio()`, `preview.select_frames_for_tiles()` (face > person > blur) and `diverse_video_frame_plan()`, and `detection._nms()`/`embedding_distance()` (IoU boundary, numpy cosine fallback, zero-vector guard). |
