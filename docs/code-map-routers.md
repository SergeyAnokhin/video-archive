# Code Map — Backend HTTP API (routers)

Part of the [code map](code-map.md). **Update this file whenever router files are added, moved, or removed.** The routers stay thin — domain logic lives in the modules mapped in [code-map-backend.md](code-map-backend.md). Keep entries short: endpoints plus genuinely non-obvious behavior only.

## `backend/app/routers/`

| Path | Role |
| --- | --- |
| [`backend/app/routers/health.py`](../backend/app/routers/health.py) | `GET /api/health`; `GET /api/health/thread-dump` returns every live thread's name + stack (`sys._current_frames()`), the diagnostic for a job that stops logging and never returns — job handlers run on threads named `job-<id8>`. |
| [`backend/app/routers/system_stats.py`](../backend/app/routers/system_stats.py) | `GET /api/system/stats` — whole-process-tree CPU/memory via `psutil` (includes ffmpeg children) plus the cumulative SMB byte counter. Feeds the top-bar gauge, `resource_monitor.py`, and the Performance history chart. |
| [`backend/app/routers/app_info.py`](../backend/app/routers/app_info.py) | `GET /api/app/info` — version, ffmpeg availability/version, and the cached hardware encode/decode probe results. |
| [`backend/app/routers/source.py`](../backend/app/routers/source.py) | `GET/PUT /api/source`, `GET /api/source/status` (read-only live check, safe to poll), `POST /api/source/test-connection`, `POST /api/source/reconnect`. `PUT` upserts a saved `sources` row then runs `source_switch.switch_active_source()` (response carries `detected_backups`/`auto_restored`/`scan_job`); resubmitting the active source's own `(protocol, root_path)` is a **reconnect** instead — same row, connection params updated in place, `scan_job: null`. Per-protocol flags: `direct_access_enabled` (SMB-only), `verify_ssl` (WebDAV-only); credentials go to `secrets_store` per source id. `GET /source/smb-lock-status` / `POST /source/smb-lock-status/release` stay independent of `_check_connection_status()` so they respond even while the SMB lock is wedged; the status also carries `waiters` (queued behind the current holder) and `orphaned_waiters` (stranded on a lock a previous release retired — unreachable, restart required). |
| [`backend/app/routers/sources.py`](../backend/app/routers/sources.py) | Saved sources: `GET /api/sources` (preview-cache stats live for the active source only), `POST /api/sources/{id}/activate`, `DELETE /api/sources/{id}` (400 for the active one; never touches that source's disk), `DELETE /api/sources/{id}/preview-cache` (active source only; clears GIFs and resets has-preview flags). |
| [`backend/app/routers/tree.py`](../backend/app/routers/tree.py) | `GET /api/tree` — recursive tree from `path`, optional `depth`, `include_status`, `include_top_tags` (opt-in, adds per-node `top_tags`). |
| [`backend/app/routers/directories.py`](../backend/app/routers/directories.py) | `GET /api/tree` and `GET /api/directories/children` (both with opt-in `include_status`/`include_top_tags`), plus folder create/delete/favorite delegating to `directory_ops.py`. |
| [`backend/app/routers/files.py`](../backend/app/routers/files.py) | `GET /api/files` (directory/recursive/search/tag filters, paginated), `GET /api/files/{id}`, preview serving (`/preview`, `/preview.jpg`, `/preview.gif` — a variant borrows its original sibling's asset), tag endpoints, `GET /{id}/similar`, `GET /{id}/media-info` (read-through cache, see `media_probe.py`), `DELETE /{id}` and `POST /{id}/move` (delegate to `file_ops.py`). |
| [`backend/app/routers/playback.py`](../backend/app/routers/playback.py) | `GET /api/files/{id}/playback` (mode + stream URL + direct path) and `GET /api/files/{id}/stream` — a manual Range-aware `StreamingResponse` over `access.open_range()`, one code path for both protocols. |
| [`backend/app/routers/playback_settings.py`](../backend/app/routers/playback_settings.py) | `GET/PUT /api/playback-settings`. |
| [`backend/app/routers/conversion_profiles.py`](../backend/app/routers/conversion_profiles.py) | `GET/POST /api/conversion-profiles`, `PUT/DELETE /api/conversion-profiles/{id}`. `preset` field (ffmpeg `-preset`, default `medium`) rides along with every other profile field, no separate validation beyond the Pydantic model. |
| [`backend/app/routers/conversion_settings.py`](../backend/app/routers/conversion_settings.py) | `GET/PUT /api/conversion-settings`. |
| [`backend/app/routers/preview_layouts.py`](../backend/app/routers/preview_layouts.py) | `GET/POST /api/preview-layouts`, `PUT/DELETE /api/preview-layouts/{id}` (409 `preset_protected` for built-ins), stateless `POST /api/preview-layouts/preview` (live tile geometry for the editor). |
| [`backend/app/routers/preview_settings.py`](../backend/app/routers/preview_settings.py) | `GET/PUT /api/preview-settings` — PUT is a full replace, the frontend always sends the merged object. |
| [`backend/app/routers/tags.py`](../backend/app/routers/tags.py) | `GET /api/tags` (`query`/`active_only`/`limit`/`category="ai"\|"user"`), `GET /api/tags/used` (any pool, usage-ordered — feeds every add-tag autocomplete), `POST /api/tags` (409 on duplicate), `PUT/DELETE /api/tags/{id}`. Every tag response includes `color` (stored or fallback). |
| [`backend/app/routers/tagging_settings.py`](../backend/app/routers/tagging_settings.py) | `GET/PUT /api/tagging-settings`; `POST /api/tagging-settings/preview` — stateless "what the model sees" demo: builds real tagging images from a file id with arbitrary (possibly unsaved) params, returned as base64 JPEG data URLs. |
| [`backend/app/routers/tag_lab.py`](../backend/app/routers/tag_lab.py) | `POST /files/{id}/tag-lab/prepare|run|apply` and the like/dislike feedback endpoints. Catches `TagLabError` and maps its `code` to an HTTP status — every provider-call failure becomes 400, carrying the raw provider reply in `detail.error`. |
| [`backend/app/routers/providers.py`](../backend/app/routers/providers.py) | Provider entry CRUD + reorder, API-key set/clear (presence and masked suffix only), `GET /providers/{id}/models` (live catalog where supported), usage summary, and model-pricing read/refresh/import/export. `_list_models_error()` is the shared provider-call error mapping. |
| [`backend/app/routers/jobs.py`](../backend/app/routers/jobs.py) | Job endpoints: `GET /api/jobs` (+ filters), `GET /{id}`, `GET /{id}/items`, `POST /{id}/cancel\|pause\|resume\|restart`, `DELETE /{id}`, `DELETE /api/jobs`. Triggers: `rescan-directory` (`with_media_info` picks the `rescan_with_media_info` job type), `convert-directory`/`convert-file`, `preview-directory`/`preview-file`, `tag-directory`/`tag-file`, `cleanup-stale-records`, `optimize-database`. `POST /generate-conversion-script` is synchronous with no job row. `GET/DELETE /api/jobs/batch-submissions[/{id}]` must stay declared *above* `GET /jobs/{id}` — see [architecture.md](architecture.md). |
| [`backend/app/routers/logs.py`](../backend/app/routers/logs.py) | `GET /api/logs` (filters: `job_id`, `file_id`, `level`, `limit`) and `GET /api/logs/stream` — SSE polling `app_events` past the last-seen rowid every 0.5s. |
| [`backend/app/routers/log_files.py`](../backend/app/routers/log_files.py) | Raw log file download/delete, for a backend running on a Kubernetes PVC with no direct disk access. `GET /api/log-files` lists whatever is in `logging_config.LOG_DIR` (rotated backups appear automatically); `GET /{filename}` streams one as an attachment; `DELETE /{filename}` refuses the active `backend.log` with 409. `filename` must be a bare name resolving inside `LOG_DIR` (path-traversal guard). |
| [`backend/app/routers/log_rotation_settings.py`](../backend/app/routers/log_rotation_settings.py) | `GET/PUT /api/log-rotation-settings` — `{max_bytes, backup_count}` for `backend.log`'s rotation; `PUT` also pushes the change onto the live handler via `logging_config.apply_rotation_settings()`. |
| [`backend/app/routers/backups.py`](../backend/app/routers/backups.py) | `GET/POST /api/backups` (POST creates a `backup` job), `POST /api/backups/restore` (a `restore` job), `DELETE /api/backups/{id}` (synchronous). Source switching calls `app/backup.py` directly, not through here. |
| [`backend/app/routers/backup_settings.py`](../backend/app/routers/backup_settings.py) | `GET/PUT /api/backup-settings`. |
| [`backend/app/routers/interface_settings.py`](../backend/app/routers/interface_settings.py) | `GET/PUT /api/interface-settings` — the request model is built with `pydantic.create_model()` from `interface_settings.py`'s field/range constants, so validation stays in sync automatically. |
| [`backend/app/routers/performance_settings.py`](../backend/app/routers/performance_settings.py) | `GET/PUT /api/performance-settings`. |
| [`backend/app/routers/resource_monitor_settings.py`](../backend/app/routers/resource_monitor_settings.py) | `GET/PUT /api/resource-monitor-settings` — `{enabled, interval_seconds}` for `app/resource_monitor.py`'s periodic CPU/memory sampler. |
| [`backend/app/routers/resource_monitor_history.py`](../backend/app/routers/resource_monitor_history.py) | `GET /api/resource-monitor-history?range=30m\|4h\|12h\|24h` (default `24h`) — thin wrapper over `app/resource_monitor_history.py`'s `get_history()` for the Settings → Performance chart. |
| [`backend/app/routers/backend_health_settings.py`](../backend/app/routers/backend_health_settings.py) | `GET/PUT /api/backend-health-settings` — `{slow_timeout_seconds, offline_timeout_seconds}` for the status dot's poll/retry timeouts. |
| [`backend/app/routers/app_settings.py`](../backend/app/routers/app_settings.py) | `GET /api/settings/app-settings/export` (downloadable JSON bundle) / `POST .../import` (returns applied counts). Thin wrapper over `app/app_settings.py`. |
