# Code Map — Backend HTTP API (routers)

Part of the [code map](code-map.md). **Update this file whenever router files are added, moved, or removed.** The routers stay thin — domain logic lives in the modules mapped in [code-map-backend.md](code-map-backend.md). Keep entries short: endpoints plus genuinely non-obvious behavior only.

## `backend/app/routers/`

| Path | Role |
| --- | --- |
| [`backend/app/routers/health.py`](../backend/app/routers/health.py) | `GET /api/health`. |
| [`backend/app/routers/system_stats.py`](../backend/app/routers/system_stats.py) | `GET /api/system/stats` — `{cpu_percent, memory_rss_bytes, memory_percent, smb_bytes_transferred_total, timestamp}` for the top-bar gauge. CPU/memory cover the whole process tree (ffmpeg children included); `cpu_percent` is normalized to a 0-100 share of total system CPU. `smb_bytes_transferred_total` is `smb_stats.py`'s cumulative in-memory counter (resets on restart; the frontend derives the rate itself). In `_QUIET_ROUTES`. |
| [`backend/app/routers/app_info.py`](../backend/app/routers/app_info.py) | `GET /api/app/info` (version, `platform.windows` (`os.name == "nt"`, lets the frontend gate the SMB source's Windows-only "direct access" checkbox), active source, DB status, queue summary, ffmpeg availability); `GET /api/app/network-info` (LAN addresses + ports; backend port read off the request itself, correct through the Vite proxy). |
| [`backend/app/routers/source.py`](../backend/app/routers/source.py) | `GET/PUT /api/source`, `GET /api/source/status` (read-only live connection check, safe to poll), `POST /api/source/test-connection`, `POST /api/source/reconnect` (no-op for `local`). `PUT` upserts a saved `sources` row then runs `source_switch.switch_active_source()`; response includes `detected_backups`/`auto_restored`/`scan_job` (the connect scan runs as a background `rescan` job, not synchronously) — resubmitting the active source's own `(protocol, root_path)` is a reconnect instead (same row, `host`/`port`/credentials/`direct_access_enabled`/`name` updated in place after a pre-flight `smb_test_connection()` check, `scan_job: null`), see [architecture.md](architecture.md). SMB `root_path` is `share[/subpath]`; credentials go to `secrets_store` per source id; `webdav` → 400. `direct_access_enabled` (migration 39, SMB-only — silently forced `False` for `protocol=local`) persists the opt-in Windows UNC fast path threaded into `SMBBackend` by `sources.get_source_access()`; `/source/status` and `/source/reconnect` both report its live `direct_access_active` state via `SourceAccess.direct_access_status()`, see `local_copy()`'s doc row in [architecture.md](architecture.md). |
| [`backend/app/routers/sources.py`](../backend/app/routers/sources.py) | Saved sources: `GET /api/sources` (preview-cache stats live for the active source only), `POST /api/sources/{id}/activate`, `DELETE /api/sources/{id}` (400 for the active one; never touches that source's disk), `DELETE /api/sources/{id}/preview-cache` (active source only; clears GIFs and resets has-preview flags). |
| [`backend/app/routers/tree.py`](../backend/app/routers/tree.py) | `GET /api/tree` — recursive tree from `path`, optional `depth`, `include_status`, `include_top_tags` (opt-in, adds per-node `top_tags`). |
| [`backend/app/routers/directories.py`](../backend/app/routers/directories.py) | `GET /api/directories/children` (subfolders + files, optional `include_top_tags`), `GET /api/directories/preview.gif?path=`, `POST /api/directories`, `DELETE ?path=` (empty only), `PUT /favorite`, `GET /favorites` (delegating to `directory_ops.py`), `GET /search?q=` (paginated folder-name search for the `path:` scope). |
| [`backend/app/routers/files.py`](../backend/app/routers/files.py) | `GET /api/files` (directory/recursive/search/tag filters, paginated), `GET /api/files/{id}`, preview serving (`/preview`, `/preview.jpg`, `/preview.gif`; a variant borrows its original sibling's asset via `_preview_source_row()`), tag endpoints (`GET/POST/DELETE /{id}/tags[/{tag_id}]`, `POST /{id}/tags/user-defined`), `GET /{id}/similar`, `GET /{id}/media-info` (read-through cache on `files.width/height/video_codec/format_name/bit_rate/duration_seconds/media_probed_at`, migration 37; on a cache miss, probes via `local_copy()` with one bounded retry and persists the result, `probe_failed` flag in the response), `DELETE /{id}` and `POST /{id}/move` (delegate to `file_ops.py`). |
| [`backend/app/routers/playback.py`](../backend/app/routers/playback.py) | `GET /api/files/{id}/playback` (mode + stream URL + direct path) and `GET /api/files/{id}/stream` — a manual Range-aware `StreamingResponse` over `access.open_range()`, one code path for both protocols. |
| [`backend/app/routers/playback_settings.py`](../backend/app/routers/playback_settings.py) | `GET/PUT /api/playback-settings`. |
| [`backend/app/routers/conversion_profiles.py`](../backend/app/routers/conversion_profiles.py) | `GET/POST /api/conversion-profiles`, `PUT/DELETE /api/conversion-profiles/{id}`. |
| [`backend/app/routers/conversion_settings.py`](../backend/app/routers/conversion_settings.py) | `GET/PUT /api/conversion-settings`. |
| [`backend/app/routers/preview_layouts.py`](../backend/app/routers/preview_layouts.py) | `GET/POST /api/preview-layouts`, `PUT/DELETE /api/preview-layouts/{id}` (409 `preset_protected` for built-ins), stateless `POST /api/preview-layouts/preview` (live tile geometry for the editor). |
| [`backend/app/routers/preview_settings.py`](../backend/app/routers/preview_settings.py) | `GET/PUT /api/preview-settings` — PUT is a full replace, the frontend always sends the merged object. |
| [`backend/app/routers/tags.py`](../backend/app/routers/tags.py) | `GET /api/tags` (`query`/`active_only`/`limit`/`category="ai"\|"user"`), `GET /api/tags/used` (any pool, usage-ordered — feeds every add-tag autocomplete), `POST /api/tags` (409 on duplicate), `PUT/DELETE /api/tags/{id}`. Every tag response includes `color` (stored or fallback). |
| [`backend/app/routers/tagging_settings.py`](../backend/app/routers/tagging_settings.py) | `GET/PUT /api/tagging-settings`; `POST /api/tagging-settings/preview` — stateless "what the model sees" demo: builds real tagging images from a file id with arbitrary (possibly unsaved) params, returned as base64 JPEG data URLs. |
| [`backend/app/routers/tag_lab.py`](../backend/app/routers/tag_lab.py) | The synchronous single-file alternative to `POST /jobs/tag-file`: `POST /files/{id}/tag-lab/prepare` (images/prompt only), `POST .../run` (→ `run_id` + raw reply/full JSON/usage/ranked tags, nothing written), `POST .../apply`, `POST /tag-lab/runs/{run_id}/feedback`. A `tag_lab_failed` error also carries the raw response when parsing failed. |
| [`backend/app/routers/providers.py`](../backend/app/routers/providers.py) | `GET/POST /api/settings/provider-entries`, `PUT/DELETE .../{id}` (keys never echoed), `POST .../reorder`, `POST .../models`, `GET .../export` (**includes plaintext keys** — deliberate, frontend warns first), `POST .../import`; `GET /api/settings/provider-usage`; `GET/PUT /api/settings/model-pricing` + `POST .../refresh-openrouter`; `GET /api/settings/model-ratings`. |
| [`backend/app/routers/jobs.py`](../backend/app/routers/jobs.py) | Job endpoints: `GET /api/jobs` (+ filters), `GET /{id}`, `GET /{id}/items`, `POST /{id}/cancel\|pause\|resume\|restart`, `DELETE /{id}`, `DELETE /api/jobs` (clear finished). Triggers: `rescan-directory`, `convert-directory`/`convert-file` (`variants` requires test mode), `preview-directory`/`preview-file`, `tag-directory`/`tag-file` (400 `no_provider_configured`/`empty_tag_vocabulary`), `cleanup-stale-records`, `optimize-database`. `GET/DELETE /api/jobs/batch-submissions[/{id}]` — declared *above* `GET /jobs/{id}` because a literal path segment must precede a same-method `/{id}` route or Starlette swallows it as an id. |
| [`backend/app/routers/logs.py`](../backend/app/routers/logs.py) | `GET /api/logs` (filters: `job_id`, `file_id`, `level`, `limit`) and `GET /api/logs/stream` — SSE polling `app_events` past the last-seen rowid every 0.5s. |
| [`backend/app/routers/backups.py`](../backend/app/routers/backups.py) | `GET/POST /api/backups` (POST creates a `backup` job), `POST /api/backups/restore` (a `restore` job), `DELETE /api/backups/{id}` (synchronous). Source switching calls `app/backup.py` directly, not through here. |
| [`backend/app/routers/backup_settings.py`](../backend/app/routers/backup_settings.py) | `GET/PUT /api/backup-settings`. |
| [`backend/app/routers/interface_settings.py`](../backend/app/routers/interface_settings.py) | `GET/PUT /api/interface-settings` — the request model is built with `pydantic.create_model()` from `interface_settings.py`'s field/range constants, so validation stays in sync automatically. |
| [`backend/app/routers/performance_settings.py`](../backend/app/routers/performance_settings.py) | `GET/PUT /api/performance-settings`. |
| [`backend/app/routers/backend_health_settings.py`](../backend/app/routers/backend_health_settings.py) | `GET/PUT /api/backend-health-settings` — `{slow_timeout_seconds, offline_timeout_seconds}` for the status dot's poll/retry timeouts. |
| [`backend/app/routers/app_settings.py`](../backend/app/routers/app_settings.py) | `GET /api/settings/app-settings/export` (downloadable JSON bundle) / `POST .../import` (returns applied counts). Thin wrapper over `app/app_settings.py`. |
