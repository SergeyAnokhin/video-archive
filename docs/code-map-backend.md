# Code Map — Backend

Part of the [code map](code-map.md). HTTP routers are mapped separately in [code-map-routers.md](code-map-routers.md); backend tests in [code-map-tests.md](code-map-tests.md). **Update this file whenever backend application files are added, moved, or removed.** Keep entries short — what lives there and when to go there; rationale and history live in git.

## `backend/` — FastAPI

| Path | Role |
| --- | --- |
| [`backend/package.json`](../backend/package.json) | Wraps the Python startup (`pip install` + `uvicorn --reload`, host `0.0.0.0`) so the root `npm run dev` can start it. |
| [`backend/requirements.txt`](../backend/requirements.txt) | Python deps: FastAPI, Uvicorn, SQLAlchemy, sse-starlette, python-dotenv, pytest, `opencv-python-headless`/`onnxruntime`/`Pillow`/`numpy` (previews), `httpx` (provider calls + `TestClient`), `smbprotocol` (whose bundled `smbclient` module is what `sources/smb_backend.py` actually uses). |
| [`backend/app/main.py`](../backend/app/main.py) | FastAPI app: on startup runs `init_db()`, checks ffmpeg once, requeues stalled batch-tagging jobs, starts the `JobWorker` (stopped on shutdown), and wires up every router. |
| [`backend/app/config.py`](../backend/app/config.py) | App version, SQLite DB path, `SECRETS_PATH`, `PREVIEW_CACHE_DIR`. |
| [`backend/app/network_info.py`](../backend/app/network_info.py) | `get_lan_addresses()` — best-effort local IPv4 discovery (UDP-connect routing trick + `getaddrinfo`, every lookup wrapped in `try/except OSError`) for Settings → Network. |
| [`backend/app/db.py`](../backend/app/db.py) | SQLite via SQLAlchemy Core. Ordered `MIGRATIONS` map + single-row `schema_meta`; `init_db()` runs pending migrations then seeds default settings rows via their owning modules. Conventions: append new migrations, never edit applied ones; use `IF NOT EXISTS` DDL (a crash between DDL and the version bump makes retries re-run statements); `get_engine()` sets WAL + `busy_timeout` since worker and request threads share the pool. |
| [`backend/app/secrets_store.py`](../backend/app/secrets_store.py) | The only reader/writer of git-ignored `backend/secrets.env`: provider API keys keyed by entry id (`PROVIDER_ENTRY_<id>_API_KEY`), per-source SMB credentials (`SOURCE_<id>_USERNAME`/`_PASSWORD` via each `sources` row's `username_ref`/`secret_ref`). HTTP-facing callers only ever get presence (`has_entry_api_key`) or a masked suffix. **Convention:** other modules must use `secrets_store.SECRETS_PATH` by attribute access (tests monkeypatch it there), never import the path from `app.config` directly. |
| [`backend/app/tags.py`](../backend/app/tags.py) | Tag vocabulary CRUD + `normalize_tag_key()`; `list_top_tags_for_files()` (batched top-N per file for the grid, `score > 0` only); manual tag editing via `get_or_create_tag()`/`assign_file_tag()`/`remove_file_tag()` (always `score=100`, `provider_name="manual"`); `assign_tuning_parameter_tags()` (`provider_name="tuning"`) used by variant sweeps. |
| [`backend/app/tagging_settings.py`](../backend/app/tagging_settings.py) | Tagging settings singleton: `sample_frame_count`, `combine_into_collage`, `top_tag_count`. |
| [`backend/app/provider_entries.py`](../backend/app/provider_entries.py) | User-managed, priority-ordered AI provider entry CRUD (`PROVIDER_TYPES` = openrouter/gemini/fal/mistral; any number of entries per type). `reorder_entries()` rewrites `sort_order` (the fallback priority). Reads expose `has_api_key`/`key_suffix` via `secrets_store`, never the key. |
| [`backend/app/tagging.py`](../backend/app/tagging.py) | Tag-job frame preparation: `sample_frames()` + `build_tagging_images()` → one composed collage or one JPEG per frame, ready to attach to a provider request. |
| [`backend/app/providers/`](../backend/app/providers/) | Vision-provider clients, one module per type. [`base.py`](../backend/app/providers/base.py): shared `build_prompt()`/`parse_scores()` (index-ordered 0-100 scores as a bare JSON array), `ProviderError`, `UsageInfo`. [`openrouter.py`](../backend/app/providers/openrouter.py)/[`mistral.py`](../backend/app/providers/mistral.py): OpenAI-compatible chat completions; [`gemini.py`](../backend/app/providers/gemini.py): `generateContent`; [`fal.py`](../backend/app/providers/fal.py): best-effort (no fixed schema — searches the whole response for the score array, no usage, no model listing). `list_models()` on openrouter/gemini/mistral; `create_batch()`/`poll_batch()` on gemini/mistral only. [`registry.py`](../backend/app/providers/registry.py): dispatches per *entry* (resolves model + key), logs every call through `provider_usage.log_usage()` (the single choke point for usage recording), and exposes `score_tags_with_fallback()` (priority-ordered chain with a per-job `dead_entry_ids` set), `entry_supports_batch()`, and the batch dispatch helpers. |
| [`backend/app/provider_usage.py`](../backend/app/provider_usage.py) | `provider_usage_log` writes (`log_usage()`, never raises), `estimate_cost_usd()` (hand-maintained `$/1M tokens` table — rough estimate, `None` for unknown models), `get_usage_summary()` for the Settings usage table. |
| [`backend/app/ffmpeg.py`](../backend/app/ffmpeg.py) | Locates ffmpeg on `PATH` and reads its version (startup availability check only). |
| [`backend/app/conversion.py`](../backend/app/conversion.py) | ffmpeg/ffprobe building blocks: `probe_media()`, `effective_max_dimension()`, `build_ffmpeg_command()`, `run_ffmpeg()`, `validate_converted_output()`, `encode_variant_suffix()`. Reused by preview/tagging/similarity and the on-demand media-info endpoint. **Convention:** both subprocess calls pass `encoding="utf-8", errors="replace"` — decoding with the OS console codepage silently truncates output on non-ASCII (e.g. Cyrillic) paths. |
| [`backend/app/conversion_profiles.py`](../backend/app/conversion_profiles.py) | Conversion profile CRUD; setting `is_default` clears it on all others; deletion unconditional. |
| [`backend/app/preview_layouts.py`](../backend/app/preview_layouts.py) | Layout preset CRUD (built-ins raise `PresetProtectedError`) + `compute_layout_tiles()` — the single source of truth for collage grid geometry, shared with the frontend through the live-preview endpoint; `seed_builtin_presets()`. |
| [`backend/app/preview_settings.py`](../backend/app/preview_settings.py) | Preview settings singleton: aspect ratio (`effective_aspect_ratio()`, default `phone-landscape` 19.5:9), GIF `gif_max_width`/`gif_colors`, animated-preview `animated_source_mode` (`frame`/`clip`), `animated_segment_seconds`, `animated_transition` (`cut`/`crossfade`). |
| [`backend/app/playback_settings.py`](../backend/app/playback_settings.py) | Playback settings singleton: `mode: "stream" \| "direct_link"`. |
| [`backend/app/backup_settings.py`](../backend/app/backup_settings.py) | Backup settings singleton: `retention_count`. |
| [`backend/app/interface_settings.py`](../backend/app/interface_settings.py) | Interface settings singleton: `language`, `theme_preset` (`THEME_PRESETS` tuple, mirrored in the router `Literal` and `frontend/src/types/api.ts`), two preview-stylization profiles (`PROFILE_FIELDS`/`PROFILE_RANGES`/`DEFAULT_PROFILE_A`/`_B` — applied client-side as CSS filters), and search limits (`SEARCH_LIMIT_FIELDS`, per-group caps for unscoped search). |
| [`backend/app/performance_settings.py`](../backend/app/performance_settings.py) | Performance settings singleton: `parallel_workers` (default 4, clamped 1-16), read once at job launch by `jobs/convert.py`/`jobs/preview.py` to bound their `ThreadPoolExecutor`s. |
| [`backend/app/backup.py`](../backend/app/backup.py) | `create_backup()` (zip with `manifest.json` + `data.json`, optional secrets copy, into the source's `.video-archive/backups/` via `SourceAccess`, then retention trim), `list_backups()`, `delete_backup()`, `restore_backup()` (validates, replaces the source-scoped tables in one transaction, upserts global settings tables unless `include_global=False` — the flag source switching uses so a switch never touches app-wide settings). |
| [`backend/app/source_switch.py`](../backend/app/source_switch.py) | `switch_active_source()` — the shared activation flow for `PUT /api/source` and `POST /api/sources/{id}/activate`: back up the outgoing source onto its own disk, flip `is_active`, wipe source-scoped tables + job history, auto-restore the incoming source's own backup if present (`include_global=False`, `RestoreError` falls back to a fresh scan), then scan to reconcile drift. |
| [`backend/app/sampling.py`](../backend/app/sampling.py) | `sample_interior_timestamps(duration, count)` — interior segment boundaries avoiding the video's start/end; shared by preview and tagging. |
| [`backend/app/detection.py`](../backend/app/detection.py) | Lazy, best-effort local detection for frame ranking: YuNet faces + SFace embeddings (auto-downloaded to `backend/models/`), YOLOv8n persons (`yolov8n.onnx` must be placed manually — no stable download URL), `blur_score()` (Laplacian variance), `_nms()`. Every `get_*()` loader returns `None` on any failure so callers degrade to blur-only ranking. cv2 face calls are serialized behind `_cv2_face_lock` (shared mutable detector state vs. parallel preview threads); `detect_persons()`/`blur_score()` are stateless and unlocked. |
| [`backend/app/preview.py`](../backend/app/preview.py) | Collage + animated-GIF rendering: `extract_frame_image()`/`extract_clip_frames()`/`fill_missing_frames()` (ffmpeg per timestamp), `select_frames_for_tiles()` (face > person > blur for enlarged tiles, identity diversity via `embedding_distance`), `render_collage()`, `render_gif()` (per-position segments, `cut`/`crossfade`), `generate_file_preview()` (optional `max_workers` for parallel extraction, optional GIF output, `on_stage` progress callback). Folder GIFs: `diverse_video_frame_plan()` (pure — splits the frame budget across subfolders/videos for visual variety) + `pick_representative_frames()`/`pick_representative_segments()`. |
| [`backend/app/similarity.py`](../backend/app/similarity.py) | Near-duplicate detection via 64-bit aHash signatures over 8 interior frames: `compute_signature()`, `store_signature()`, `find_similar()` (Hamming distance, threshold 10/64). Computed only as a best-effort side effect of the preview job. |
| [`backend/app/media.py`](../backend/app/media.py) | File-naming rules and markers: supported extensions, `.video-archive` technical folder, `folder-preview.gif`, `is_test_artifact()` (`.original.`/`.variant-`), `sibling_relative_path()` (posix-only, SMB-safe), `preview_gif_relative_path()` (flattened collision-free GIF names), `variant_base_stem()`/`parse_variant_suffix()`/`compute_variant_tags()` (recover a variant's origin and swept parameters from its name), `resolve_variant_preview_flags()` (variants borrow their original sibling's `has_preview_asset` in listings). |
| [`backend/app/preview_cache.py`](../backend/app/preview_cache.py) | Local per-source preview cache under `backend/preview_cache/<source_id>/` (previews are never written to the source): `collage_path()`/`gif_path()`/`folder_gif_path()`, `cache_stats()`, `clear_cache()`. **Convention:** tests must patch `preview_cache.PREVIEW_CACHE_DIR` directly (same attribute-access rule as `secrets_store.SECRETS_PATH`). |
| [`backend/app/file_ops.py`](../backend/app/file_ops.py) | Single-file move/delete domain logic (file + sibling preview assets + DB rows), raising `FileOperationError` with the API error code; keeps `routers/files.py` thin. |
| [`backend/app/directory_ops.py`](../backend/app/directory_ops.py) | Folder create / delete (empty-only, deliberately non-recursive) / favorite domain logic, raising `DirectoryOperationError`; keeps `routers/directories.py` thin. |
| [`backend/app/scan.py`](../backend/app/scan.py) | `discover_filesystem()` walks a source via `SourceAccess.walk()`; `upsert_directory()`/`upsert_file()`; `scan_source()` (local convenience wrapper) / `scan_source_access()` (protocol-agnostic entry point). |
| [`backend/app/status.py`](../backend/app/status.py) | `compute_directory_status()` — derived per-subtree conversion/preview completeness, counts, `total_size_bytes`, `top_variant_tags`; excludes test artifacts; never persisted. |
| [`backend/app/source_access.py`](../backend/app/source_access.py) | `get_active_source_or_404()` helper for the browsing routers — not the `app/sources/` layer, despite the similar name. |
| [`backend/app/sources/`](../backend/app/sources/) | Uniform file-access layer — all scan/convert/preview/tag/playback/backup file access goes through here instead of raw `pathlib`: [`entries.py`](../backend/app/sources/entries.py) (shared dataclasses), [`local_backend.py`](../backend/app/sources/local_backend.py) (thin passthroughs; `local_copy()`/`stage_output_dir()` are no-ops), [`smb_backend.py`](../backend/app/sources/smb_backend.py) (`smbclient` over UNC paths, `_with_retry()` re-registers the session once on connection errors, `local_copy()` downloads to a temp file / `commit_new_file()` uploads back, module-level `test_connection()`), [`access.py`](../backend/app/sources/access.py) (`SourceAccess` facade + `get_source_access()` factory reading credentials from `secrets_store`). |
| [`backend/app/jobs/service.py`](../backend/app/jobs/service.py) | Job/job-item CRUD and the `queued → running → paused → completed\|failed\|cancelled` state machine. `log_event()` writes `app_events` and mirrors errors/warnings (plus `_CONSOLE_INFO_EVENT_TYPES`) to the console, prefixing a per-job file index (`[#N]`) and per-event-type emoji. In-memory cancel/pause registries + `check_stop_requested()` (the single cooperative checkpoint handlers call); a *second* cancel on a running job force-finishes it (`job_force_cancelled`) for handlers stuck in an unbounded blocking call. `PAUSABLE_JOB_TYPES` (per-item-loop types only); `set_job_total_items()` (Jobs-modal progress/ETA); `run_retention_sweep()` (24h). Every function opens its own short transaction. |
| [`backend/app/jobs/worker.py`](../backend/app/jobs/worker.py) | `JobWorker` — two `_Lane` threads: CPU lane (everything except `tag`), network lane (`tag`), each claiming only its own job types, so one CPU job and one tag job can run concurrently. Handlers run on a joinable side thread; if a force-cancel finishes the job out-of-band, the lane logs `job_force_abandoned` and moves on rather than staying wedged behind an unresponsive handler. |
| [`backend/app/jobs/rescan.py`](../backend/app/jobs/rescan.py) | `rescan` handler: walk the target subtree, batch-upsert directories, per-file job items (live progress + cancellation between files), remove stale rows. |
| [`backend/app/jobs/convert.py`](../backend/app/jobs/convert.py) | `convert` handler. Directory scope: recursive, skip-processed, excludes test artifacts, processes `parallel_workers` files per batch. File scope: one production/test conversion, or a variant sweep (`parallel_workers` variants at a time; outputs upserted by suffix-derived name; each variant tagged with its effective parameters via `tags.assign_tuning_parameter_tags()`, best-effort). Safe replace everywhere: encode to temp → `validate_converted_output()` → commit only on success; test mode renames the original instead. Emits per-stage `job_item_progress` events (probe/encode/validate). |
| [`backend/app/jobs/preview.py`](../backend/app/jobs/preview.py) | `preview` handler. File scope: render collage + GIF into a throwaway temp dir, copy into the local preview cache, set `has_preview_asset`, then best-effort `_try_store_similarity_signature()`. Directory scope: `parallel_workers` files at a time, skip-processed (self-healing — re-checks the cached file actually exists), then folder GIFs for the target and every descendant directory (diverse frame plan, mode-aware segments). Emits `job_item_started` (with `item_key` = relative path) and per-stage `job_item_progress` events. |
| [`backend/app/jobs/tag.py`](../backend/app/jobs/tag.py) | `tag` handler. First checks for a pending batch submission and resumes it if found. Otherwise per file: `local_copy()` → `tagging.build_tagging_images()` → `registry.score_tags_with_fallback()` (priority order, per-job dead-entry set) → replace the file's tag set with the top-N `score > 0` results, recording the producing entry's provider/model. Directory scope: skip-processed on `tagged_at`, excludes test artifacts; delegates to `tag_batch.run_batch()` first when a batch-capable entry is enabled, then per-file for the remainder. |
| [`backend/app/jobs/tag_batch.py`](../backend/app/jobs/tag_batch.py) | Persistent batch-tagging orchestration, split from `tag.py` (which it imports the per-file fallback from — `tag.py` imports it lazily to avoid the circular import). Picks the single highest-priority batch-capable enabled entry, submits all pending files in one request, **persists the submission before polling** (`batch_submissions`), polls every 30s with 1s interruptible sleeps (pause/cancel just leaves the submission `polling`), falls back to the per-file chain for anything unresolved. `resume_directory_scope()` rebuilds vocabulary/tag order from the submission's own snapshot after a restart and finalizes from `job_items` counts. |
| [`backend/app/batch_submissions.py`](../backend/app/batch_submissions.py) | `batch_submissions` table CRUD: one row per accepted batch (external id, exact tag order + file mapping, `top_tag_count` snapshot). `list_active()` backs the batch-jobs modal; `forget()` marks a row `forgotten` (no provider-side cancel — the owning job falls back per-file); `requeue_stalled_jobs()` (startup) re-queues `tag` jobs left `running` mid-poll. |
| [`backend/app/jobs/cleanup.py`](../backend/app/jobs/cleanup.py) | `cleanup` handler: deletes DB rows whose file/directory no longer exists on the source (directories checked deepest-first); never discovers new files or refreshes metadata. |
| [`backend/app/jobs/optimize_db.py`](../backend/app/jobs/optimize_db.py) | `optimize_db` handler: `VACUUM` + `ANALYZE` on an AUTOCOMMIT connection; no job items. |
| [`backend/app/jobs/backup.py`](../backend/app/jobs/backup.py) | `backup` handler — thin job wrapper over `backup.create_backup()`; no job items. |
| [`backend/app/jobs/restore.py`](../backend/app/jobs/restore.py) | `restore` handler — wraps `backup.restore_backup()`, reporting `RestoreError` as a normal job failure; no job items. |

## Notes, known gaps, and conventions

- **Runtime-created, git-ignored artifacts:** `backend/secrets.env` (created on first write by `secrets_store.py`), `backend/models/` (detection models downloaded on demand), `backend/preview_cache/`, `backend/video_archive.db`.
- **Singleton settings convention:** a global scalar setting gets its own single-row table (`id` fixed to 1) — never a generic key-value table. Adding one touches the same ~8 places; copy `playback_settings`'s shape end to end: (1) a migration in `db.py`, (2) a seeding block in `init_db()`, (3) `app/<name>_settings.py`, (4) `app/routers/<name>_settings.py` (`GET`/`PUT`), (5) wire into `main.py`, (6) a type in `frontend/src/types/api.ts`, (7) a `frontend/src/components/<Name>SettingsSection.tsx`, (8) register in `SettingsModal.tsx`'s `TABS` + `en.json`/`ru.json` keys.
- **Non-ASCII paths on Windows:** never use `cv2.imread(path)` (silently returns `None`) — read bytes via `np.fromfile()` + `cv2.imdecode()`; always pass `encoding="utf-8", errors="replace"` to ffmpeg/ffprobe subprocess calls (see `conversion.py`).
- **Known gap:** `HTTPException` bodies are nested under FastAPI's default `{"detail": {"error": {...}}}` rather than a top-level `{"error": {...}}`; no custom exception handler is registered.
- **External-integration caveats:** `fal.py` is best-effort (no fixed response schema). The Gemini/Mistral batch clients were built against the documented API shape and are covered by mocked tests, but a real successfully-resolving batch job has not been exercised end-to-end; a submission/poll failure degrades to per-file tagging rather than losing tags.
- **SMB costs:** preview/tagging over `smb` download each needed video to a local temp copy per run, with no cross-run caching — acceptable at target archive sizes. SMB code is tested against an in-memory fake of `smbclient` (`tests/conftest.py`), not a real server.
- **Diagnosing "every file fails to probe":** a 100% `"Source is not a probeable video..."` run usually means the backend process can't see ffprobe on `PATH` at all (typically a stale dev-server process predating the ffmpeg install) — restart the backend; see [development.md](development.md).
